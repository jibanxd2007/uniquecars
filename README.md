# Unique Cars (NZ) Ltd — Production Landing Page

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Live%20Demo-black?logo=vercel&style=flat-square)](https://uniq-flame.vercel.app/)

A high-performance, editorial automotive finance portal built for **Unique Cars (NZ) Ltd**, registered motor vehicle trader based in Manurewa, Auckland, New Zealand.

🌐 **Live Production URL**: [https://uniq-flame.vercel.app/](https://uniq-flame.vercel.app/)  
📁 **Repository**: [https://github.com/jibanxd2007/uniquecars](https://github.com/jibanxd2007/uniquecars)

---

## ✨ Key Features

- **Interactive Amortization Calculator**: Real-time weekly repayments with slider and quick-preset chips ($15k, $20k, $35k, $50k).
- **3-Step Application Wizard**:
  1. Personal contact & residential information.
  2. Vehicle selection with dynamically populated Japanese import models (Toyota Aqua, Prius, Hilux, RAV4, etc.).
  3. Real-time application summary and automatic reference code generation (e.g. `UC-20601`).
- **Statutory CCCFA Disclosures**: Accessible modal dialogs detailing rates, terms, and conditions for Avanti Finance, Finance Now, Auto Finance Direct, and Go Car Finance.
- **Unified Dealership Support & FAQ**: Direct phone calling, Auckland showroom location, opening hours, and expandable FAQ accordions.
- **Accessibility & Performance**:
  - Full WCAG 2.2 AA luminance contrast compliance across all brand colors.
  - Near-perfect Google Lighthouse scores (99 Performance, 96 Accessibility, 96 Best Practices, 100 SEO).
  - Responsive layout verified across Desktop (1440px), Laptop (1280px), Tablet (768px), and Mobile (375px).

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, modern ES Modules JavaScript
- **Styling**: Vanilla CSS with customized design tokens and zero heavy CSS framework overhead
- **Bundler**: Vite 6
- **Deployment**: Vercel

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/jibanxd2007/uniquecars.git
cd uniquecars

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
